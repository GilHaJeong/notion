# 오라토리오 단일 통합 웹앱 · 내부 검증본 v0.1

상태: INTERNAL_REVIEW_ONLY / RUNTIME_CHECKS_PASS / CANONICAL_NOT_APPROVED / PUBLIC_NOT_DEPLOYED

## 실행

1. ZIP을 풀고 `app/index.html`을 Chromium/Chrome 등 브라우저로 엽니다.
2. 내 파트를 고르고 다음을 누릅니다. 재생 검증에는 테너 전체를 선택합니다.
3. 홈 → No.1 → 구간 선택 → 연습하기 → 재생을 누릅니다.
4. 시작·끝 마디, 트랙, 속도, 반복 켜짐/꺼짐을 바꾸고 자가 체크를 기록합니다.
5. 홈의 라오디게아 카드에서 실제 악보와 해설 ③을 확인합니다. 이 곡의 음원은 미연결이므로 재생을 막았습니다.

`app/index.html`은 이미지·MP3·JSON·CSS·JS를 포함하는 독립 HTML입니다. 서버·외부 CDN·로그인 없이 테스트할 수 있습니다. 최초 외부 스트리밍도 사용하지 않습니다. 전체 제1부 다운로드, 중단 이어받기, 패치 설치, PWA/service worker는 이번 구현 범위가 아닙니다.

로컬 저장소를 사용할 수 있는 경우 같은 브라우저·같은 HTML 경로에서 파트·구간·연습 기록을 복구합니다. 브라우저 데이터 삭제, HTML 경로 변경, 임베드의 저장소 제한에서는 유지가 보장되지 않습니다. 접근 거부 시 앱에 경고를 표시하고 메모리 상태로만 동작합니다.

## 통합 범위

- FIX-002의 화면·상태·저장 계약을 근거로 한 5개 흐름: 첫 실행, 홈, 곡 목록, 곡 상세, 연습.
- NO01 v0.4 패키지의 실제 Tenor/Piano control stem 두 개. 공통 Web Audio 시간축에서 재생·트랙 전환·속도·마디 반복.
- NO01 원본 PDF p.3 / 인쇄 p.7 근거 이미지. 첫 시스템은 원본 PNG에서 새로운 crop을 만들어 반주 저음 오선까지 보존.
- 라오디게아 인쇄 p.149 / PDF p.145 이미지 및 L32-03 승인 좌표.
- 기존 해설 후보를 뜻/부를 때/조심할 것으로 표시. 새로운 신학·서사 해설은 만들지 않음.
- 36곡은 목록 자리만 유지. NO01 이외의 연습 버튼은 자료 미연결로 비활성.

## 엄격한 경계

- NO01 MusicXML·음원은 후보입니다. 실제 가창, 정본 악보, production package가 아닙니다.
- 마디 커서는 q=86, nominal 4/4 후보 시간축입니다. notehead 위치나 PDF 마디별 하이라이트로 표시하지 않습니다.
- m.1/7/15/18 후보 이벤트 이상과 Piano voice 구조는 수정·정본화하지 않았습니다.
- No.1 첫 PDF 페이지만 포함합니다. 다른 페이지가 필요한 구간에서도 근거 페이지로만 표시하며 전체 악보 coverage를 주장하지 않습니다.
- S/A/B 및 세부 파트 분리 음원은 없습니다. 해당 선택에서는 Tenor를 내 파트로 잘못 연결하지 않고 Piano만 허용합니다.
- 라오디게아 실제 파트 음원·timeline은 미연결입니다.
- 원본 라오디게아 후보 파일의 `NO36_laodicea` packageId는 L32-03/No.31–33 계보와 충돌합니다. 앱에서는 숫자 곡 번호를 재지정하지 않고 `laodicea` 검증 사례로 격리합니다. 원본 JSON은 변경하지 않았습니다.
- 기준 질감 파일은 번들링하지 않았습니다. 세 레이어 슬롯은 유지하고 비활성화했으며 승인되지 않은 질감을 생성하지 않았습니다.
- UI 계약 원본 JSON 3종은 그대로 보존합니다. 추가 검증 문구·컨트롤·화면 흐름은 `CONTRACT_REVIEW.md`에 내부 검증용 역제안으로 기록했으며 공식 계약 준수/승격을 주장하지 않습니다.
- 실제 태블릿 70–90cm 판독, 음정·가사·음가의 음악 QA, 청취 품질, 공개·배포 승인은 이번 PASS 범위 밖입니다.

## 개발

`app/app.js`, `app/styles.css`, `app/data/`가 편집 원본입니다. `python build.py`로 독립 HTML을 다시 생성합니다. `qa/`에는 실행 검사 코드·JSON 결과·직접 확인한 화면이 포함됩니다. QA 스크립트의 브라우저/Playwright 경로는 실행 환경에 맞게 조정해야 합니다.

`source/fix.zip`, `source/no01.zip`은 회수한 원본 패키지입니다. 원본과 파생 자산 해시는 `manifest.json`에 기록되어 있습니다.

# No.1 whole-file playback v0.5

Home: explicit Whole song button starts the existing 21-measure candidate render from zero. No default looping. Pause/resume retains position; Stop resets to zero. Range practice is opt-in, with looping only if the user chooses it. Existing scores, narratives and two MP3 files are reused unchanged.

Files in app/v05 are generated by build_v05.py from app/v04. Place the builder at the repository root and run Python. It requires v04 and existing app/assets; this patch is not a standalone full media bundle.

Existing source is MIDI-level synthesized audio, not a verified raw .mid file or canonical transcription. Known m1/7/15/18/Piano issues remain visible. Score/audio automatic synchronization and actual singing are not newly implemented.

QA: whole-test.cjs runs a real uninterrupted full-file pass, not a seek-to-end substitute. Browser checks do not constitute acoustic listen or physical-tablet approval.
